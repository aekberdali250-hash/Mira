# سوقك — منصة صفحات بيع المنتجات

منصة عربية RTL لإنشاء صفحات بيع مستقلة، تجهيز فيديو تسويقي بسيط من صورة المنتج (تحريك/تكبير تدريجي مع عناوين)، وتصدير المنشور للنشر اليدوي على فيسبوك، وإدارة الطلبات.

## التشغيل محليًا
1. ثبّت Node.js 18 أو أحدث.
2. افتح مجلد المشروع في Terminal.
3. نفّذ:
   ```bash
   npm install
   ```
4. عيّن متغيرات البيئة:
   - `ADMIN_PASSWORD` كلمة مرور لوحة الإدارة
   - `SESSION_SECRET` قيمة طويلة وعشوائية
5. شغّل:
   ```bash
   npm start
   ```
6. افتح `http://localhost:3000`

## النشر على Render
1. ارفع ملفات هذا المجلد إلى مستودع GitHub جديد.
2. في Render أنشئ Web Service من المستودع أو استخدم Blueprint عبر `render.yaml`.
3. أضف `ADMIN_PASSWORD` من إعدادات Environment، وضع كلمة مرور قوية.
4. اضبط `SESSION_SECRET` بقيمة عشوائية طويلة.
5. اضغط Deploy.

## ملاحظات مهمة
- النسخة الأولى تحفظ البيانات في ملفات JSON محلية. تخزين Render المحلي قد يُمسح عند إعادة النشر أو إعادة تشغيل الخدمة، وقد لا يكون دائمًا. للاستخدام التجاري الحقيقي، أضف PostgreSQL أو قرصًا دائمًا.
- ملفات الصور المرفوعة على Render قد لا تبقى بشكل دائم ما لم تضف Persistent Disk أو تخزينًا خارجيًا. هذه النسخة مناسبة للاختبار الأولي.
- الفيديو يتم إنشاؤه داخل المتصفح كفيديو Canvas مع حركة بسيطة وصوت اختياري/بدون صوت. قد تختلف إمكانية التسجيل حسب المتصفح. يمكن تنزيله ونشره يدويًا.
- لا يوجد نشر آلي إلى Facebook في هذه النسخة؛ النشر اليدوي يتجنب الحاجة إلى صلاحيات Meta ومراجعة التطبيق.
- لا تجمع بيانات زبائن لا تحتاجها، واحمِ لوحة الإدارة. جهّز سياسة خصوصية وشروط بيع وتوصيل قبل الإطلاق التجاري.
